# Students for Abundance - Berkeley Chapter Website

Website for the Berkeley chapter of Students for Abundance, modeled after the national website at https://studentsforabundance.org/

## Project Structure

```
.
├── public/          # Static assets (images, fonts, etc.)
├── src/             # Source code
│   ├── css/         # Stylesheets
│   ├── js/          # JavaScript
│   └── pages/       # HTML pages
├── index.html       # Homepage
└── README.md        # This file
```

## Getting Started

1. Clone this repository
2. Set up your preferred development environment
3. Make changes to files in `src/`
4. Test locally before committing
